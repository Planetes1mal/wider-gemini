Make Gemini and ChatGPT fit your screen

Open Gemini or ChatGPT, then click the Wider Gemini toolbar icon. Choose the site tab to adjust its settings.

Task presets
In the Gemini tab, choose Long reading, Tables, Code, or Large text, review the settings, then click Apply. These change Gemini's width, font size, spacing, and code wrapping. Your width limits still apply. Restore previous settings undoes the most recent task preset on this device, even after closing the popup; it replaces any later changes to those settings.
Conversation width
Choose px for a fixed width or % to follow the window size. Move the slider or choose a preset. Gemini and ChatGPT save width, limits, and presets separately; each unit has its own presets. Expand Range & presets to edit them. The switch beside the width title pauses widening for that site and restores its original width. Your saved values and presets are kept; Gemini reading settings remain active.
Code wrapping
In the Gemini tab, turn on Code Auto Wrap to read long lines without as much horizontal scrolling. Turn it off to preserve unbroken code lines. ChatGPT keeps its native code formatting.
Text size & spacing
In the Gemini tab, adjust font size from 75% to 200% without zooming the whole page. At Auto density 0, native paragraph gaps and line-height proportions are preserved. Higher density gradually reduces native spacing. Advanced spacing sets exact manual values; Reset spacing returns to Auto at the current density. ChatGPT keeps its native text size and spacing.

Changes apply to open tabs for the selected site and are saved automatically. Sync across devices depends on your browser's sync settings.

Something looks wrong?

  1. Check that you are on gemini.google.com or chatgpt.com and Wider Gemini has access to that site. Chrome-installed site app windows use the same webpages. Native desktop apps and Chrome's built-in Gemini panel are not supported.
  2. If a setting does not appear after installing or updating the extension, reload the affected page once. An unsupported-layout notice means widening is not applied to the current page, so its original width is preserved. You can also pause widening for just that site using its width switch.
  3. If the problem continues, note the site, steps to reproduce it, and your window size. A screenshot with private content removed can help; mention any other extensions that change the page layout.
Report a problem

Settings report

Generate a report to preview before sharing it in an issue. It includes only the extension version, browser major version, platform, Gemini layout settings, and ChatGPT width settings. It contains no chats, page URLs, titles, or custom preset names. Nothing is sent automatically.
