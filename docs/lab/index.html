Designing a responsive search interface

A fast search experience begins with deciding which work belongs in the browser and which belongs on the server. Sending a request for every keystroke creates redundant work. Debouncing waits until typing pauses, while request cancellation stops an older response from replacing newer results. Neither technique makes a slow query fast: indexing and caching solve different parts of the problem.

Start with one clear rule: the latest query owns the screen. Preserve keyboard focus as results arrive, explain when no matches are found, and keep the current query visible after a network failure. A small response cache can make repeated searches feel immediate, but its expiry must match how quickly the underlying data changes.

這份範例包含說明段落、六欄比較表和一段搜尋程式碼。請依下方的三個題目閱讀與查找，並保持相同的視窗與文字大小。「統一寬度」與「正文限寬」呈現相同內容；完成兩個區塊後，再記錄哪一種較適合你的任務，以及理由。

Keep the latest query in control

JavaScript · illustrative snippetWrapped
let timer;
let request;

function search(query) {
    clearTimeout(timer);
    request?.abort();
    const current = new AbortController();
    request = current;
    timer = setTimeout(async () => {
        try {
            const response = await fetch(`/api/search?q=${encodeURIComponent(query)}&include=title,summary,updatedAt&sort=relevance`, { signal: current.signal });
            if (!response.ok) throw new Error(`HTTP ${response.status}`);
            const results = await response.json();
            if (request === current) renderResults(results);
        } catch (error) {
            if (error.name !== 'AbortError' && request === current) showError(error.message);
        }
    }, 300);
}

The controller is created for each query and captured by that query's callback. The identity check before rendering makes the ownership rule explicit. The user still needs a visible loading state, a useful empty state, and a way to retry a failed request.

參考答案 / Answer key

Cancellation avoids showing stale responses; caching reuses earlier results. Cache expiry: 60 s. Inverted index: server. Debounce: 300 ms. Render only when request === current.
