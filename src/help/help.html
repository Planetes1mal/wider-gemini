Make Gemini and ChatGPT fit your screen

Open Gemini or ChatGPT, then click the Roomy toolbar icon. Choose the site tab to adjust its settings.

Gemini access is required. ChatGPT access is optional: select ChatGPT and allow access in the popup.

Task presets
Choose a task preset, review the summary, then click Apply. Gemini offers Long reading, Tables, Code, and Large text; ChatGPT offers Long reading, Wide (tables & code), and Large text. Presets change width, font size, and spacing (and code wrapping in Gemini), within your width limits. Restore previous settings undoes the most recent preset for that site on this device, even after closing the popup; it replaces later changes to those settings.
Conversation width
Choose px for a fixed width or % to follow the window size. Move the slider or choose a preset. Gemini and ChatGPT save width, limits, and presets separately; each unit has its own presets. Expand Range & presets to edit them. The switch beside the width title pauses widening for that site and restores its original width. Your saved values and presets are kept; reading settings remain active.
Code wrapping
Gemini only: Turn on Code Auto Wrap to read long lines without as much horizontal scrolling. In ChatGPT, use its own wrap button on each code block; the extension leaves it unchanged.
Text size & spacing
Font size ranges from 75% to 200% without zooming the whole page, keeping headings, code, and tables in proportion. At Auto density 0, native paragraph gaps and line heights are preserved; higher density gradually tightens prose only. On both sites, code lines and table cells keep their native line-height proportions. ChatGPT formulas also keep their native spacing. Advanced spacing sets exact manual values; Reset spacing returns to Auto at the current density. Gemini and ChatGPT keep separate reading settings.

Changes apply to open tabs for the selected site and are saved automatically. Sync across devices depends on your browser's sync settings.

Something looks wrong?

  1. Check that you are on gemini.google.com or chatgpt.com and Roomy has access to that site. Chrome-installed site app windows use the same webpages. Native desktop apps and Chrome's built-in Gemini panel are not supported.
  2. If a setting does not appear after installing or updating the extension, reload the affected page once. If the popup says the page runs an older version, reload the extension on chrome://extensions first. An unsupported-layout notice means widening is not applied to the current page. Use the Enable switch below the site tabs to pause everything on a site; saved settings are kept.
  3. If the problem continues, note the site, steps to reproduce it, and your window size. A screenshot with private content removed can help; mention any other extensions that change the page layout.
Report a problem

Settings report

Generate a report to preview before sharing it in an issue. It includes only the extension version, browser name and major version, platform, interface language, each site's Enable switch, Gemini layout settings, and ChatGPT width and reading settings. It contains no chats, page URLs, titles, or custom preset names. Nothing is sent automatically.
