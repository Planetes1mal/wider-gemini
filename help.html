Make Gemini fit your screen

Open Gemini, then click the Wider Gemini toolbar icon to adjust your settings.

Task presets
Choose Long reading, Tables, Code, or Large text, review the settings, then click Apply. These change width, font size, spacing, and code wrapping. Your width limits still apply. Restore previous settings undoes the most recent task preset on this device, even after closing the popup; it replaces any later changes to those settings.
Conversation width
Choose px for a fixed width or % to follow the window size. Move the slider or choose a preset; each unit has its own presets.
Code wrapping
Turn on Code Auto Wrap to read long lines without as much horizontal scrolling. Turn it off to preserve unbroken code lines.
Text size & spacing
Adjust font size from 75% to 200% without zooming the whole page. At Auto density 0, native paragraph gaps and line-height proportions are preserved. Higher density gradually reduces native spacing. Advanced spacing sets exact manual values; Reset spacing returns to Auto at the current density.

Changes apply to open Gemini tabs and are saved automatically. Sync across devices depends on your browser's sync settings.

Something looks wrong?

  1. Check that you are on gemini.google.com and Wider Gemini is enabled. It also works with this website installed as a Chrome app (PWA). Google's native desktop apps are not supported.
  2. If a setting does not appear after installing or updating the extension, reload the Gemini page once and try again.
  3. If the problem continues, note the steps to reproduce it and your window size. A screenshot with private content removed can help; mention any other extensions that change Gemini's layout.
Report a problem

Settings report

Generate a report to preview before sharing it in an issue. It includes only the extension version, browser major version, platform, and layout settings. It contains no chats, page URLs, titles, or custom preset names. Nothing is sent automatically.
