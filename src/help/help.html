Help & feedback

Make your AI chats fit your screen

Open a supported website, then click the Roomy toolbar icon. On a supported website the popup opens that website's settings; elsewhere it lists all websites.

Gemini access is required. Other websites are optional: click Allow next to the website in the popup's list.

Task presets
Choose a task preset, review the summary, then click Apply. Each website offers its own presets, such as Long reading, Wide (tables & code), and Large text. Presets change width, font size, and spacing (and code wrapping where available), within your width limits. Restore previous settings undoes the most recent preset for that website on this device, even after closing the popup; it replaces later changes to those settings.
Conversation width
Choose px for a fixed width or % to follow the window size. Move the slider or choose a preset. Each website saves width, limits, and presets separately; each unit has its own presets. Expand Range & presets to edit them. The switch beside the width title pauses widening for that website and restores its original width. Your saved values and presets are kept; reading settings remain active.
Code wrapping
Code auto wrap is available on Gemini. Other websites keep their own code-block wrap controls; the extension leaves them unchanged.
Text size & spacing
Font size ranges from 75% to 200% without zooming the whole page, keeping headings, code, and tables in proportion. At Auto density 0, native paragraph gaps and line heights are preserved; higher density gradually tightens prose only. Code lines and table cells keep their native line-height proportions, and formulas keep their native spacing. Advanced spacing sets exact manual values; Reset spacing returns to Auto at the current density. Each website keeps separate reading settings.

Changes are saved automatically and apply live to open tabs of that website. Each website keeps separate settings; the popup language is shared. Sync across devices depends on your browser's sync settings.

Something looks wrong?

  1. Check that you are on a supported website and Roomy is enabled with access to that website. Chrome-installed web apps (PWAs) use the same webpages. Native desktop apps and Chrome's built-in Gemini panel are not supported.
  2. If a setting does not appear after installing or updating the extension, reload the affected page once. If the popup says the page runs an older version, reload the extension on chrome://extensions first. An unsupported-layout notice means widening is not applied to the current page. Use the switch beside the website name to pause everything on that website; saved settings are kept.
  3. If the problem continues, note the site, steps to reproduce it, and your window size. A screenshot with private content removed can help; mention any other extensions that change the page layout.
Report a problem

Settings report

Generate a report to preview before sharing it in an issue. It includes only the extension version, browser name and major version, platform, interface language, and each website's Enable switch, width, range, and reading settings. It contains no chats, page URLs, titles, or custom preset names. Nothing is sent automatically.
